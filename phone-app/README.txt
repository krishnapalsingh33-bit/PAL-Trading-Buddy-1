PAL TRADING BUDDY — ANDROID APP

This is a real installable Android APK, not a saved webpage. It opens PAL in a native Android WebView with no browser address bar, uses the PAL Trading Buddy launcher icon, and includes a retry screen if the hosted app takes too long to open.

The app requires internet access because live quotes, news, calendar and analysis are served by the hosted PAL API.

Install steps:
1. Download PAL-Trading-Buddy-Android.apk from the build artifact or the direct APK download provided in chat.
2. Open the APK on your Android phone.
3. If Android asks, allow your browser/file manager to install unknown apps, then install PAL Trading Buddy.

Hosted dashboard: https://pal-market-data-api.onrender.com/dashboard

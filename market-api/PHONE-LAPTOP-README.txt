PAL TRADING BUDDY — PHONE & LAPTOP PORTABLE BUILD

Included file:
- PAL-Trading-Buddy-Mobile.html

How to use:
1. Extract this ZIP.
2. Open PAL-Trading-Buddy-Mobile.html in an up-to-date browser.
3. Allow an internet connection; live quotes, analysis, calendar and news are served by PAL's hosted API.
4. The page refreshes automatically. Use "Refresh all feeds" to request another update.
5. Add the hosted dashboard to your phone's home screen for the most reliable app-like experience:
   https://pal-market-data-api.onrender.com/dashboard

Important:
- The portable HTML file is a browser dashboard, not a native Android APK.
- Quote timestamps determine freshness. If the upstream price provider does not return fresh data, the dashboard shows that status instead of making up prices.
- Gold is a GC=F futures proxy, not spot XAU/USD.
- Right Now Bias prefers current intraday momentum; when it must fall back to the daily change, the card labels that direction "DAILY" and requests intraday confirmation.

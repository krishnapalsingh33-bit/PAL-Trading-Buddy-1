# PAL Trading Buddy — Mobile App

This repository now includes a mobile-ready Progressive Web App (PWA) shell for PAL Trading Buddy.

## Use on Android / iPhone

1. Open the deployed PAL Trading Buddy website in your phone browser.
2. Android Chrome: use **Add to Home screen** / **Install app**.
3. iPhone Safari: tap **Share** → **Add to Home Screen**.
4. Launch **PAL Buddy** from the home screen.

The mobile shell uses the existing PAL frontend and backend; no trading or market-analysis logic is changed.

## Important

The installed web app still needs the normal PAL backend/API deployment to provide live market and macro data. The PWA shell itself only makes the existing frontend installable on a phone.
